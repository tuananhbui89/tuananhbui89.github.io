# Diffusion tutorial completion materials

Research, source archives, section drafts, figure provenance, and validation records are stored in `_research/`. The leading underscore keeps these working materials out of Jekyll's published site. The tutorial is `_posts/2025-03-08-diffusion-foundation.md`; its published illustrations are in `assets/img/diffusion-foundation/`.

- `_research/completion/edit-manifest.json`: exact authorized edit spans and hashes of unchanged original text.
- `_research/completion/tutorial-completion.diff`: comparison against the original tutorial.
- `_research/completion/*sources.md`: primary references and figure provenance.
- `_research/completion/visual-qa/`: illustration checks at desktop and mobile widths.
- `_research/papers/`: downloaded paper materials used for the completion.
