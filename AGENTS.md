## Rules for managing repository and files

- `.scratch/` contains temporary generated material. Save the temporary material in this folder if a task does not relate to creating a blog post or blog post's assets. For example, if a task is "use $youtube-transcript skill to summarize a video", then the generated transcript should be saved to the `.scratch/` folder. If a task is "use $lecture-noter skill to create a series of blog posts about a Youtube series" then the related materials should not be saved in the `.scratch/` folder.
- `docs_map.md` provides a map of commonly used locations in this workspace.

## Writing for this website

- Before creating or revising website prose, read [the example-based writing guide](.bad_examples/avoid_bad_examples.md). It is the maintained source of detailed writing rules and before/after evidence. Scale its guidance to the content: a long technical tutorial needs more orientation than a short news item.
